# Privacy Policy — Tarif Atölyesi Uploader

*Last updated: 22 November 2026*

**Tarif Atölyesi Uploader** is a private tool used only by the owner of the YouTube channel [Tarif Atölyesi (@tarifatolyesi)](https://www.youtube.com/@tarifatolyesi) to upload the owner's own videos to that channel.

## YouTube API Services
This tool uses **YouTube API Services**. By using it you also agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms).
Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## What data is accessed
With the channel owner's OAuth consent (scopes `youtube.upload` and `youtube.force-ssl`) the tool:
- uploads the owner's own video files, titles, descriptions, tags and Turkish caption files (`videos.insert`, `captions.insert`);
- reads and updates the owner's own channel and video metadata (`channels.list`, `channels.update`, `channelBanners.insert`, `videos.list`, `videos.update`).

It does **not** access, collect, store or share any data of other YouTube users, and it does not use cookies or analytics.

## Storage and sharing
The OAuth access/refresh token is stored only on the owner's own computer and is never sent to any server other than Google, never sold and never shared. Upload logs (video IDs and times) are kept locally only.

## Deletion and revocation
Access can be revoked at any time via [Google security settings](https://myaccount.google.com/permissions). On revocation the local token becomes invalid and is deleted; locally stored upload logs can be deleted on request within 7 days.

## Contact
Via the YouTube channel [@tarifatolyesi](https://www.youtube.com/@tarifatolyesi) or the [GitHub repository](https://github.com/mertaydogdu10-wq/tarif-atolyesi).

# Gizlilik Politikası — Tarif Atölyesi Uploader

**Tarif Atölyesi Uploader**, yalnızca [Tarif Atölyesi](https://www.youtube.com/@tarifatolyesi) YouTube kanalının sahibinin kendi videolarını kendi kanalına yüklemek için kullandığı özel bir araçtır.

**YouTube API Hizmetleri:** Bu araç YouTube API Hizmetlerini kullanır. Kullanarak [YouTube Hizmet Şartları](https://www.youtube.com/t/terms)'nı da kabul etmiş olursunuz. Google'ın veri işleme uygulamaları [Google Gizlilik Politikası](https://policies.google.com/privacy)'nda açıklanmıştır.

**Erişilen veriler:** Yalnızca kanal sahibinin kendi videoları, başlık/açıklama/etiketleri, altyazıları ve kanal bilgileri. Başka hiçbir kullanıcının verisine erişilmez, saklanmaz, paylaşılmaz; çerez veya analiz kullanılmaz.

**Saklama:** Yetkilendirme belirteci yalnızca kanal sahibinin bilgisayarında saklanır, satılmaz ve paylaşılmaz.

**Silme / erişimi kaldırma:** Erişim [Google güvenlik ayarlarından](https://myaccount.google.com/permissions) istenildiği an kaldırılabilir; yerel kayıtlar talep üzerine 7 gün içinde silinir.
