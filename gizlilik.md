# Tarif Atölyesi Uploader — Gizlilik Politikası

Son güncelleme: 22 Kasım 2026

"Tarif Atölyesi Uploader", yalnızca **Tarif Atölyesi** YouTube kanalının sahibi tarafından, kendi kanalına video yüklemek için kullanılan özel bir araçtır.

**Toplanan veriler:** Uygulama, YouTube Data API üzerinden yalnızca kanal sahibinin kendi kanalına video, başlık, açıklama ve altyazı yüklemek ve kanal bilgilerini güncellemek için yetki ister. Üçüncü kişilere ait hiçbir veri toplanmaz.

**Saklama:** Yetkilendirme belirteci (token) yalnızca kanal sahibinin kendi bilgisayarında saklanır; hiçbir sunucuya gönderilmez, satılmaz veya paylaşılmaz.

**Google API Hizmetleri:** Uygulamanın Google API'lerinden aldığı bilgileri kullanımı, Sınırlı Kullanım şartları dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uygundur.

**Erişimi kaldırma:** Erişim istenildiği zaman https://myaccount.google.com/permissions adresinden kaldırılabilir.

**İletişim:** YouTube kanalı üzerinden: https://www.youtube.com/@tarifatolyesi
